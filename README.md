# DCT-Stego: 鲁棒性频域图像隐写工具

`DCT-Stego` 是一个基于 Go 语言实现的隐写工具，利用 **离散余弦变换 (Discrete Cosine Transform)** 在图像的频域中嵌入冗余信息。与传统的 LSB（最低有效位）修改不同，该工具通过微调中频系数的相对关系来存储数据，使其能够抵御一定程度的 JPEG 压缩和图像裁剪。

## 核心特性

* **频域嵌入**：在 DCT 变换后的 $8 \times 8$ 块中操作系数，避开敏感的低频（影响视觉）和脆弱的高频（易被压缩抹除）。
* **自适应冗余 (Adaptive Delta)**：算法会根据图像局部区域的能量（AC 分量）动态调整嵌入强度，在平滑区域保持隐蔽，在复杂区域增强鲁棒性。
* **分块传输协议**：
    * **魔数同步**：内置 20-bit 序列用于自动对齐数据包。
    * **CRC16 校验**：有效过滤因图像干扰产生的误码。
    * **自动分片**：支持长 URL 自动切片并携带序列 ID 嵌入。
* **抗位移攻击**：解码器具备 64 像素范围内的滑动窗口搜索能力，支持在图像被微量裁剪后提取数据。

## 算法原理

本项目实现的隐写逻辑遵循以下流程：

1.  **分块与变换**：将输入图像转化为 YCbCr 亮度平面，切分为 $8 \times 8$ 像素块进行 DCT 变换。
2.  **差值量化**：选取特定的中频系数对 $(AC_{18}, AC_9)$。
    * **Bit 1**: 调整系数使 $|AC_{18}| > |AC_9| + \Delta$
    * **Bit 0**: 调整系数使 $|AC_9| > |AC_{18}| + \Delta$
3.  **逆变换还原**：通过 IDCT 将修改后的频域数据还原为 RGB 像素。

## 快速开始

### 编译

```bash
go build -o stego main.go
```

### 嵌入信息 (Encode)

将 URL 嵌入到 `input.png` 中，生成支持 JPEG 压缩的水印图：

```bash
./stego encode -in input.png -out output.jpg -format jpg -quality 92 -url "https://your-secret-link.com"
```

* `-quality`: 建议设置在 90 以上以获得最佳还原率。
* `-url`: 支持 URL 标准字符集及 `|` 填充符。

### 提取信息 (Decode)

从带水印的图中还原原始信息：

```bash
./stego decode -in output.jpg
```

## 注意事项与建议

* **色彩空间**：本工具目前直接在 RGBA 像素上计算亮度贡献。为获得更好的抗压缩效果，建议输入高对比度或纹理丰富的图像。
* **安全性增强**：当前版本的魔数与系数位置是硬编码的。若用于敏感环境，请在代码中修改 `magicBits` 及 `ia/ib` 的索引位置，或在嵌入前对 URL 进行加密处理。
* **性能说明**：解码过程采用全位移搜索逻辑，对于超大分辨率图片（4K+）可能耗时较长。
